# geomersive-tile-utils

Small Web Mercator (XYZ) tile helpers used by the Geomersive viewer.

## Testing

Requires Node.js 22 or later. Install dev dependencies with npm ci first. Run the command from the repository root.


```
node --test
```

This runs the tests in `test/` and should report `# pass 4` and `# fail 0`.

## Sample data

`samples/tile-bbox.json` is a small sample area (Oslo, zoom 10) used as example input.
